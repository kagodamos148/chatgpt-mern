# chatgpt-mern-project

This is a customized chatGPT Application. Using the reference from the youtube. This is initial MERN project.
Feel free to follow below steps if you are first timer like myself.

## Installation
1. Install Node https://nodejs.org/en
2. Install React project from following command
   - `npx create-react-app <project-name>`
   - start server `npm start`
